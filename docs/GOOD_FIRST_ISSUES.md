# Good first contributions

These are proposed tasks, not claims of existing external contributors. Open a focused issue before starting and include fictional reproduction data.

| Task                             | Acceptance                                                                                                         |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Expand bilingual search examples | Add real everyday Hebrew/English query cases with expected positives and negatives; retain existing passing cases. |
| Keyboard/screen-reader review    | Document one reproducible focus/label problem and a small fix verified in both directions.                         |
| Mobile browser checklist         | Test Safari/Chrome quick add, details, backup and theme; report browser/version and fictional steps only.          |
| Explain backup bounds            | Improve Hebrew/English recovery help without implying unlimited exports or cloud sync.                             |
| Improve contributor setup        | Verify documented clean install on Windows/Linux and propose accurate instructions.                                |

Do not add fake stars/users, private backup samples, paid APIs or another framework just to increase activity.
